## 🚀 Como Usar a Demo

### Primeira Execução

Quando você abrir o aplicativo pela primeira vez, verá uma tela de boas-vindas com duas opções:

1. **🎮 Carregar Demonstração** (Recomendado)
   - Carrega automaticamente 4 obras de exemplo
   - 12 capítulos no total
   - 60 páginas com capas e páginas geradas
   - Permite testar todas as funcionalidades imediatamente

2. **📝 Começar do Zero**
   - Inicia com biblioteca vazia
   - Você pode importar suas próprias obras

**Recomendação**: Clique em "Carregar Demonstração" para ver o app funcionando!

## ⌨️ Atalhos do Teclado

### No Leitor
- `→` ou `Espaço`: Próxima página
- `←`: Página anterior
- `↑`: Página anterior (modo vertical)
- `↓`: Próxima página (modo vertical)
- `ESC`: Voltar para detalhes da obra

## 🎯 Fluxo de Teste Recomendado

### Teste 1: Explorar a Biblioteca
1. Abra o app
2. Clique em "Carregar Demonstração"
3. Vá para "Biblioteca" na sidebar
4. Veja as 4 obras carregadas
5. Clique em uma obra para ver detalhes
6. Observe a capa, informações e capítulos

### Teste 2: Ler uma Obra
1. Na biblioteca, clique em "Solo Leveling"
2. Clique em "Capítulo 01"
3. O leitor abrirá
4. Navegue pelas páginas usando clique ou setas
5. Observe a barra de progresso
6. Volte e veja que o progresso foi salvo

### Teste 3: Testar Modos de Leitura
1. Leia "One Punch Man" (modo Mangá - RTL)
2. Leia "Solo Leveling" (modo Manhwa - Vertical)
3. No leitor, clique em ⚙️ e mude o modo
4. Observe a diferença na navegação

### Teste 4: Favoritos e Filtros
1. Na biblioteca, marque algumas obras como favoritas (☆)
2. Use o filtro "Favoritas"
3. Veja apenas as obras marcadas
4. Teste outros filtros (Lendo, Concluído, etc.)

### Teste 5: Estatísticas
1. Vá para "Estatísticas" na sidebar
2. Veja os gráficos de atividade
3. Observe os gêneros favoritos
4. Veja o tempo de leitura estimado

### Teste 6: Importação
1. Vá para "Importar" na sidebar
2. Escolha "Imagens Avulsas"
3. Selecione algumas imagens do seu computador
4. Preencha os metadados
5. Confirme a importação
6. Veja a nova obra na biblioteca

### Teste 7: Configurações
1. Vá para "Configurações" na sidebar
2. Ajuste o brilho padrão
3. Configure downloads simultâneos
4. Clique em "🎮 Recarregar Demo" para resetar
5. Clique em "🗑️ Limpar tudo" para zerar

## 🔄 Resetar a Demo

Se quiser recomeçar a demonstração:

1. Vá para "Configurações"
2. Role até "Armazenamento"
3. Clique em "🎮 Recarregar Demo"
4. Confirme a ação
5. O app será recarregado com dados fresh

Ou para limpar completamente:
1. Vá para "Configurações"
2. Clique em "🗑️ Limpar tudo"
3. Confirme duas vezes
4. O app será resetado
